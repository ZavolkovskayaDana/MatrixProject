# Лабораторная работа №1  
## Реализация анимации «Матрица» (C++ / WinAPI)

### Описание работы
Первая лабораторная работа представляет собой реализацию консольной анимации, имитирующей «падающие символы» из фильма *«Матрица»*.  
Программа выводит столбцы случайных символов, которые движутся сверху вниз с настраиваемой скоростью и длиной. Реализована поддержка двух режимов запуска:

1. **Диалоговый режим** — пользователь вводит параметры вручную:  
   - скорость вывода символов (1–30);  
   - длина столбцов (1–30);  
   - режим «эпилепсии» (Y/N), который включает быстрые хаотичные изменения цвета.

2. **Режим командной строки**, параметры передаются так:
matrix.exe <speed> <length> <Y/N>

### Основной функционал
- Заполнение консоли «потоками» символов.
- Настраиваемая скорость обновления.
- Настраиваемая длина колонн.
- Режим эпилепсии (усиленные цветовые эффекты).
- Проверка корректности входных данных как в диалоге, так и в командной строке.
- Структура кода разделена по классам.

### Технологии
- **C++17**
- **WinAPI** (работа с консолью)
- **CMake не используется** в данной лабораторной
- Git / GitHub для контроля версий

### Состав проекта
- `main.cpp` — точка входа программы, выбор режима запуска и управление параметрами.
- `Line.h / Line.cpp` — реализация «потоков» символов, формирование и движение строк.
- `Symbol.h / Symbol.cpp` — работа с отдельными символами, генерация и обновление отображаемых знаков.
- `SystemUtils.h / SystemUtils.cpp` — функции системного уровня (работа с вводом, консолью, утилитарные проверки).
- `AppManager.h / AppManager.cpp` — управляющий класс приложения, объединяющий логику запуска, параметров и анимации.

### Инструкция по сборке и запуску
1. Скомпилировать проект в Visual Studio (WinAPI).  
2. Запуск в диалоговом режиме:  
matrix.exe
3. Запуск в командной строке:  
3. Запуск в командной строке:  
matrix.exe <скорость 1–30> <длина 1–30> <Y/N>
