Описание проекта:

Данный проект представляет собой серию лабораторных работ по дисциплине «Программирование». Основная цель проекта — разработка консольного приложения на языке C++ с использованием объектно-ориентированного подхода.
В процессе выполнения лабораторных работ реализуются различные аспекты ООП, работа с консолью Windows, динамикой объектов, обработкой ввода и структурированием проекта через Git.

Стек технологий:

C++

WinAPI (управление консолью: размеры буфера, курсор, цвета)
CMake (опционально, если используется в сборке)
Git (ведение истории разработки, работа с ветками)
Visual Studio (основная IDE для разработки)

Структура веток репозитория:

about — содержит только документацию и общее описание проекта. Ветки с кодом в неё не включены.
develop — основная ветка разработки. Здесь ведётся работа над функционалом до его завершения.
lab-01 — реализация первой лабораторной работы. Готовая рабочая версия после проверки.

Отличия веток лабораторных работ:

lab-01 — базовая реализация программы:

классы Line, Symbol, SystemUtils, AppManager;
движение линии по экрану;
работа с консолью Windows через WinAPI;
режим командной строки и диалоговый режим;
проверка корректности пользовательского ввода.

Инструкция по сборке и запуску:

Сборка в Visual Studio
Открыть решение (.sln) в Visual Studio.
Выбрать конфигурацию Debug.
Нажать Build -> Build Solution.
Исполняемый файл будет находиться в папке x64/Debug.

Запуск приложения:

Программа может работать в двух режимах:

1. Диалоговый режим
Запуск без аргументов:

Matrix.exe

Пользователь вручную вводит параметры:
скорость;
длину линии;
флаг эпилепсии (Y/N).

2. Режим командной строки
Запуск с аргументами:

Matrix.exe <speed> <length> <Y|N>

Пример:

Matrix.exe 10 15 Y

Где:
speed — целое число 1–30 (чем меньше, тем быстрее анимация),
length — длина линии (1–30),
Y/N — режим эпилепсии, строго один символ.

Дополнительная информация

По команде:

Matrix.exe --help выводится справка по использованию программы.
