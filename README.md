# Лабораторная работа №3
## Реализация анимации «Матрица» с эффектом взрывов и полиморфной архитектурой (C++ / WinAPI)

### Описание работы
Третья лабораторная работа является дальнейшим развитием проекта из первой и второй лабораторных работ.
К существующей анимации «Матрицы» с зигзагообразным движением линий был добавлены:

  - эффект взрывов символов;

  -  переход к полиморфной архитектуре с использованием абстрактного базового класса;

  - реализовано взаимодействие нескольких типов анимируемых объектов (линий и взрывов);

  - управляемых единым менеджером приложения;

### Основной функционал
- Заполнение консоли «потоками» символов.
- Настраиваемая скорость обновления.
- Настраиваемая длина колонн.
- Режим эпилепсии (усиленные цветовые эффекты).
- Настраиваемая частота линий.
- Настраеваемая вероятность взрыва.
- Настраевыемый минимальный и максимальный радиус взрыв.
- Проверка корректности входных данных как в диалоге, так и в командной строке.
- Структура кода разделена по классам.
- Зигзагообразное движение.
- Безопасная зона по вертикали.
- Плавное появление строки.
- Плавное исчезновение.
- Независимая скорость для каждой линии.
- Эффект взрывов с независимой скоростью анимации.
- Полиморфное управление всеми объектами через базовый класс Figure.
- Корректное удаление завершившихся объектов.

### Технологии
- **C++17**
- **WinAPI** (работа с консолью)
- **SystemUtils + AppManager** для управления приложением
- **Git / GitHub** для контроля версий
- **IDE: Visual Studi**

### Состав проекта
- `main.cpp` — точка входа программы, выбор режима запуска и управление параметрами.
- `Line.h / Line.cpp` — реализация «потоков» символов, формирование и движение строк.
- `Symbol.h / Symbol.cpp` — работа с отдельными символами, генерация и обновление отображаемых знаков.
- `SystemUtils.h / SystemUtils.cpp` — функции системного уровня (работа с вводом, консолью, утилитарные проверки).
- `AppManager.h / AppManager.cpp` — управление жизненным циклом строк, запуск анимации.
- `Figure.h` — абстрактный базовый класс для всех анимируемых объектов.
- `Explosion.h / Explosion.cpp` — реализует анимацию взрыва с радиальным расширением.
